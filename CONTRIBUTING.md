# Contributing

Thank you for considering contributing! A few guidelines to help your contribution go smoothly:

- Fork the repository and create a topic branch for your changes.
- Keep changes focused and include a clear description in the PR.
- If you're adding code, make sure it follows the existing style and includes simple tests if appropriate.
- For any questions or design discussions, open an issue first.

When your PR is ready, link it to any related issue and provide steps to reproduce the change.
